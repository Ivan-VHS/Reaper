# Шесть приложений Reaper для DAK

Здесь находятся шесть независимых фундаментальных проектов на языке Reaper:

| Продукт | Назначение |
|---|---|
| Omni | Единое рабочее пространство, реестр и состояние сервисов |
| Pomni | Заметки, задачи, напоминания и личная база знаний |
| LoLo | Локальные коммуникации и очередь сообщений с явным согласием |
| PePe | Организация файлов и цифровых материалов |
| Hyper-kinetic Charge | Мониторинг телеметрии и безопасные рекомендации по производительности |
| Judo | Проверка разрешений и отчёты о состоянии безопасности |

Каждый продукт имеет отдельный каталог, исходники Reaper, сценарии smoke-проверок и application.contract.json.

Целевой объём — 20 000 строк Reaper на приложение, 120 000 строк суммарно. Текущая поставка является фундаментом, а не завершённой реализацией. Искусственное заполнение строками не допускается.

На этом этапе реализованы только детерминированные доменные функции, локальные демонстрационные точки входа и сценарии проверки. Нативный интерфейс DAK, постоянное хранилище, жизненный цикл DOM, фоновые задачи, сеть, индексирование файлов, аппаратная телеметрия, управление производительностью и изменение привилегий пока не реализованы.

Все системные эффекты должны подключаться через версионированные контракты DOM/DAK, явные разрешения, согласие пользователя, квоты, диагностику и обработку ошибок. Файловый доступ, сеть, запуск процессов, управление устройствами и привилегиями не должны возникать неявно.

Сценарии checks.rpr написаны на Reaper, но в текущей среде не запускались компилятором или runtime. Загрузка исходников в репозиторий не является доказательством успешной компиляции или готовности продукта.
