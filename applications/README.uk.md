# Шість застосунків Reaper для DAK

У цьому каталозі розміщено шість незалежних фундаментальних проєктів мовою Reaper:

| Продукт | Призначення |
|---|---|
| Omni | Єдиний робочий простір, реєстр і стан сервісів |
| Pomni | Нотатки, завдання, нагадування та особиста база знань |
| LoLo | Локальні комунікації та черга повідомлень з явною згодою |
| PePe | Організація файлів і цифрових матеріалів |
| Hyper-kinetic Charge | Моніторинг телеметрії та безпечні рекомендації щодо продуктивності |
| Judo | Перевірка дозволів і звіти про стан безпеки |

Кожен продукт має окремий каталог, вихідний код Reaper, сценарії smoke-перевірок і application.contract.json.

Цільовий обсяг — 20 000 рядків Reaper на застосунок, 120 000 рядків загалом. Поточна поставка є фундаментом, а не завершеною реалізацією. Штучне заповнення рядками не допускається.

На цьому етапі реалізовано лише детерміновані доменні функції, локальні демонстраційні точки входу та сценарії перевірки. Нативний інтерфейс DAK, постійне сховище, життєвий цикл DOM, фонові завдання, мережа, індексація файлів, апаратна телеметрія, керування продуктивністю та зміна привілеїв поки не реалізовані.

Усі системні ефекти мають підключатися через версіоновані контракти DOM/DAK, явні дозволи, згоду користувача, квоти, діагностику та обробку помилок. Доступ до файлів, мережі, запуск процесів, керування пристроями та привілеями не повинен виникати неявно.

Сценарії checks.rpr написані мовою Reaper, але в поточному середовищі не запускалися компілятором або runtime. Завантаження вихідного коду до репозиторію не є доказом успішної компіляції чи готовності продукту.
