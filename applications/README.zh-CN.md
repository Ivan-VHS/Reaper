# 面向 DAK 的六款 Reaper 应用

此目录包含六个独立的 Reaper 语言应用基础项目：

| 产品 | 用途 |
|---|---|
| Omni | 统一工作空间、产品注册表与服务状态 |
| Pomni | 笔记、任务、提醒与个人知识库 |
| LoLo | 本地通信与显式同意控制的消息队列 |
| PePe | 文件与数字资产整理 |
| Hyper-kinetic Charge | 只读遥测与安全性能建议 |
| Judo | 权限审查与安全态势报告 |

每个产品都有独立目录、Reaper 源码、烟雾检查场景以及 application.contract.json。

每款应用的目标是 20,000 行 Reaper 源码，六款应用共计 120,000 行。当前交付内容只是基础框架，并非完整实现；不允许通过无意义代码填充行数。

当前仅包含确定性的领域函数、本地演示入口和检查场景。DAK 原生界面、持久化存储、DOM 生命周期、后台任务、网络、文件索引、硬件遥测、性能控制和权限变更尚未实现。

所有系统副作用都必须通过版本化的 DOM/DAK 合约接入，并具备显式权限、用户同意、配额、诊断和错误处理。不得隐式访问文件系统、网络、进程、设备或提升权限。

checks.rpr 场景使用 Reaper 编写，但本次交付环境没有运行 Reaper 编译器或运行时。源码上传不代表编译通过或产品已完成。
