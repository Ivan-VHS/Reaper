# Improvement and conflict resolution

`improvement-conflict.v1.json` stores 20 diagnostic triplets. Terms describe categories, not proof of defects.

| Stage | Gate |
|---:|---|
| 1 | reproduce symptom |
| 2 | confirm root cause |
| 3 | define scoped change + rollback |
| 4 | branch and implement |
| 5 | test and review |
| 6 | merge after required checks and human approval |
