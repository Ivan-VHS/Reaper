# Mora integration · Reaper Studio

Reaper Studio now uses Mora as its first-run desktop theme. Its default semantic palette carries the common indigo surfaces, violet brand accent, teal focus/secondary accent, shared border and selection values. Existing light/dark and dawn/sunset/night themes remain available, with their own background choices and the same Mora brand/action tokens.

The Reaper editor, project tree, output panel, language services, debugger and runtime are unchanged. Mora unifies the Studio frame and controls without flattening syntax colors or replacing editor-specific behavior.

The portable semantic tokens are mirrored in `mora/theme.json`. Theme contrast is checked by the existing palette contract.
