# Implementation and integration ledger

| Area | Current implementation |
|---|---|
| Python | lexer/parser/runtime, CLI, REPL, modules |
| Studio | Windows editor, check/run/debug, breakpoints, call stack |
| МОСТ | exact aliases and status profile |
| Native | C17 lexer/parser/AST/IR and selected lowering |
