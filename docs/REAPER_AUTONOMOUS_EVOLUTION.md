# Reaper evolution policy

Automation may inspect, test, measure and propose isolated changes.

| Stage | Requirement |
|---|---|
| Observe | repository and CI evidence |
| Diagnose | reproducible gap |
| Propose | hypothesis, bounds, risk, rollback |
| Implement | dedicated branch |
| Verify | tests and native conformance |
| Promote | protected PR, human approval |

No self-approval, protection bypass, test weakening or fabricated benchmark claims.
