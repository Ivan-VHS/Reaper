# Quality and commercial readiness

`quality-commercial.v1.json` stores the 20×3 control matrix.

| Axis | Gate |
|---|---|
| Quality | correctness, limits, regression tests |
| Execution | repeatability, failure handling, release evidence |
| Commercial | rights, license, delivery cost, user validation |

Run `python tools/quality_commercial.py --format json`. Profile scores are not proof of revenue or market fit.
