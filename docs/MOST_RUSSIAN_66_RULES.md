# REAPER / МОСТ — 66 правил проектирования русской записи

**Редакция:** проект стандарта 0.1.  
**Статус:** 66 правил определяют только требования к читаемости и удобству русской записи. МОСТ — точный слой русских лексических псевдонимов над языком REAPER. REAPER остаётся единственным языком, компилятором, грамматикой, AST, системой типов, Canonical IR, runtime, библиотекой, ABI и набором backend. Python-эталон уже исполняет ограниченное подмножество псевдонимов; нативный C17-лексер классифицирует русский словарь. Эти факты не означают готовность полного парсера или нативного исполнения.

## 1. Нормативные принципы

1. МОСТ использует только синтаксис и конструкции REAPER.
2. Каждое русское ключевое слово — точный псевдоним существующего ключевого слова REAPER; новые операции не добавляются.
3. Русские псевдонимы преобразуются в существующие токены REAPER и затем проходят тот же parser, AST, type checker, IR и runtime.
4. Нет отдельной грамматики, морфологического движка, intent resolver, AST, системы типов, стандартной библиотеки или backend МОСТ.
5. Склонение и синонимия не угадываются. Поддерживаются только явно заданные точные написания; обычные имена остаются обычными REAPER-идентификаторами.
6. Все ошибки, эффекты, права, порядок вычислений и ограничения одинаковы у английской и русской записи.
7. Произношение, ударение, тембр, эмоции и голосовой ввод не являются частью компилятора.
8. Правила языка программирования считаются реализованными только при наличии кода, тестов и CI.

## 2. Русская запись существующего REAPER

~~~most
функция удвоить(значение) {
    вернуть значение * 2
}

пусть число := 5
переменная сумма := 0

для элемент в range(1, 4) {
    изменить сумма := сумма + удвоить(элемент)
}

если сумма == 12 {
    вывести "готово"
} иначе {
    вывести "ошибка"
}
~~~

Это рабочее подмножество Python reference runtime REAPER: русские слова переводятся в токены уже существующих конструкций \`craft/yield\`, \`make/vary/change\`, \`each/in\`, \`when/otherwise\` и \`emit\`. Полная грамматика модулей, типов и объявлений в C17 ещё не реализована; этот пример не обещает обратного.

## 4. Пределы русской лексики

МОСТ не разбирает падежи, окончания, приставки, суффиксы, синонимы и произвольные фразы. Лексер распознаёт только точные записи из таблицы псевдонимов. Например, `пусть` является псевдонимом `make`; другие падежные или разговорные варианты автоматически не выводятся.

Имена переменных и функций — обычные Unicode-идентификаторы REAPER. Пользователь может объявить несколько имён или вспомогательных функций по обычным правилам REAPER, но компилятор не объединяет их по смыслу и не ищет словарные синонимы. Ошибки разрешения имён полностью принадлежат существующему resolver REAPER.

## 5. Письменность и речь

Исходник — Unicode-текст. Регистр, NFC, допустимые символы, визуально сходные знаки и координаты Unicode должны закрепляться conformance-тестами. Ударение, интонация, тембр, эмоция, паузы и тон голоса не являются машинной семантикой. Голосовой ввод и ASR/TTS — отдельные инструменты: распознанный текст показывается пользователю; неоднозначность требует подтверждения до компиляции.

## 6. Совместимость и развитие

Русская запись и исходный REAPER-код обязаны сводиться к одному набору токенов и одной программе. Никакого второго frontend с отдельным resolver нет. Любое изменение грамматики, типов, ABI или runtime происходит только в REAPER и одинаково применяется к обоим написаниям.
