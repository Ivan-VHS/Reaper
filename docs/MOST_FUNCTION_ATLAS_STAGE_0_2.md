# MOST / Reaper Function Atlas — Stage 0.2: Contract Registry

The registry tracks 147 existing specifications and 519 proposals. Its exact inventory size is maintained in machine-readable metadata and is not used as the public product identity.

| State | Meaning |
|---|---|
| Specified | stable contract exists |
| Implemented | code and tests exist |
| Proposed | future acceptance target |
| Deprecated | retained ID, no new use |

A registry entry is not an implemented function. Use `language/functions.json` and the implementation-status ledger as the machine-readable source.
