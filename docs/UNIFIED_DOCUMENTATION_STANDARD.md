# Unified Documentation and Semantics Standard

**Canonical specification:** [DAK — Unified Documentation and Semantics Standard](https://github.com/Ivan-VHS/DAK/blob/main/docs/UNIFIED_DOCUMENTATION_STANDARD.md).

Use the shared vocabulary for implementation maturity, runtime state, verification outcome, integration policy and evidence. Reaper's language, runtime, compiler and ABI contracts remain authoritative for Reaper behavior.

The shared standard also defines the 50-point README publication gate: repository identity and metadata; evidence-backed chronology; architecture and contracts; breaking changes and limitations; sources, verification, localization, license attribution and maintenance. The local [Documentation Control](DOCUMENTATION_CONTROL.md) page records Reaper-specific review gates.
