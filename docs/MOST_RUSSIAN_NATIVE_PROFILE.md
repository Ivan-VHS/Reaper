# МОСТ — русскоязычный национальный профиль Reaper

**Версия профиля:** 0.2.0  
**Основа:** REAPER — единое каноническое ядро  
**Состояние:** 54 точных русских псевдонима; 21 исполняемый псевдоним базового подмножества и 33 лексически зарезервированных формы.

МОСТ — русскоязычная поверхность языка REAPER: исходный код можно писать русскими ключевыми словами и Unicode-идентификаторами, сохраняя один канонический парсер, модель значений, семантику, runtime, ABI и IR. Это не второй компилятор и не отдельная реализация языка.

## 1. Двадцать направлений развития

| № | Направление | Инженерное обязательство | Статус |
|---:|---|---|---|
| 01 | Язык программирования — русскоязычный | Русский исходный текст является первичным пользовательским интерфейсом; английские REAPER-написания остаются совместимым каноническим слоем. | `partial` |
| 02 | Программный язык — русский | Ключевые конструкции имеют устойчивые русские написания; пользовательские имена могут быть русскими Unicode-идентификаторами. | `partial` |
| 03 | Кодовый язык — отечественный | UTF-8 сохраняет авторский текст; диагностика использует позиции символов, а не количество байтов. | `partial` |
| 04 | Алгоритмический язык — национальный | Разбор ключевых слов детерминирован и воспроизводим; одинаковый исходный текст даёт одинаковые токены. | `implemented` |

| 08 | Вычислительный язык — славянский | Числовые типы, арифметика, ошибки и ограничения наследуются от REAPER; язык не вводит скрытых преобразований. | `implemented` |
| 09 | Системный язык — восточнославянский | Доступ к файлам, FFI, устройствам и небезопасным операциям остаётся явным и ограничивается моделью возможностей REAPER. | `specified` |

| 12 | Синтаксический язык — общенародный | Порядок операторов, блоков и выражений един для всех языковых написаний. | `partial` |
| 13 | Семантический язык — коренной | Смысл задаётся каноническим токеном, типом и контекстом; эвристические синонимы не меняют программу. | `implemented` |
| 14 | Декларативный язык — традиционный | Неизменяемость и объявления по умолчанию сохраняются; права и эффекты выражаются явно. | `partial` |
| 15 | Императивный язык — аутентичный | Изменения состояния записываются явно и проверяются правилами REAPER. | `implemented` |
| 16 | Процедурный язык — нативный | Функции и возврат результата используют существующую модель функций REAPER. | `partial` |
| 17 | Объектный язык — местный | Структуры и типы выражаются формально; владение и время жизни не выводятся из лексических названий. | `specified` |
| 18 | Модульный язык — русскоговорящий | Модули, импорты и экспорты сохраняют границы видимости, API и авторства. | `partial` |

## 3. Единая архитектура

Путь обработки исходного текста:

`UTF-8 source → exact alias lexer → canonical REAPER tokens → shared parser → shared AST/semantics → verified IR → supported backend`

- **Один источник истины:** правила языка определяются [LANGUAGE.md](../LANGUAGE.md) и спецификацией REAPER, а не отдельным МОСТ-runtime.
- **Без скрытой семантики:** русская форма не меняет тип, владение, эффекты, capability, стоимость операции или ABI.
- **Без ложного исполнения:** если каноническая конструкция пока не реализована в REAPER, её русский псевдоним остаётся лексическим резервом.
- **Совместимость:** английская и русская записи должны приводить к эквивалентному каноническому потоку токенов и одинаковому результату там, где конструкция поддерживается.
- **Диагностика:** позиции в Python и C17-лексерах считаются по Unicode code points для корректного UTF-8; байтовые смещения и правила Unicode-нормализации пока не заявляются как часть публичного API.

## 4. Пример работающей русской программы

~~~most
функция удвоить(значение) {
    вернуть значение * 2
}

пусть число := 5
переменная итог := 0

для элемент в range(1, 4) {
    изменить итог := итог + удвоить(элемент)
}

если итог == 12 {
    вывести "готово"
} иначе {
    вывести "ошибка"
}
~~~

Ожидаемый вывод: `готово`. Пример использует только 21 базовую форму, уже поддержанную Python reference runtime. Вызовы `range` и любые другие встроенные функции сохраняют канонические имена REAPER.

## 5. Права, авторство и совместимость

1. Сохранять Apache-2.0 и все существующие уведомления об авторских правах.
2. Сохранять авторство, историю происхождения, атрибуцию контрибьюторов и лицензии сторонних зависимостей.
3. Не переносить проприетарный код, тексты, наборы данных или ресурсы без необходимого разрешения и правового основания.
4. Не удалять лицензионные заголовки, товарные знаки, уведомления или условия распространения.
5. При связывании с внешними языками и API явно фиксировать ABI, лицензионные условия и границы ответственности.
6. Защита прав автора проекта не отменяет защиту прав пользователей, контрибьюторов и третьих лиц.

Русскоязычная и восточнославянская направленность описывает язык интерфейса и инженерный профиль проекта. Она не означает исключительного владения русским языком, славянским культурным наследием или общими идеями программирования.

## 6. Проверки и критерии приёмки

- Реестр содержит ровно 54 уникальных точных написания.
- Python и C17-лексеры используют одинаковые пары «русская форма → каноническое слово».
- Все канонические слова присутствуют в зарезервированном словаре native lexer.
- 21 базовый alias проходит сквозные тесты выполнения Python reference runtime.
- 33 дополнительные формы проверяются только как лексические токены, пока для них не будет принят соответствующий grammar/runtime milestone.
- Русские идентификаторы не ломают позиции диагностики: одна Unicode code point считается одной колонкой в корректном UTF-8.
- CI выполняет тесты Python, native C17 lexer и проверку целостности реестра.

Локальная проверка:

~~~sh
python tools/validate_most_keywords.py
python -m unittest discover -s tests -v
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
ctest --test-dir build --output-on-failure
~~~
