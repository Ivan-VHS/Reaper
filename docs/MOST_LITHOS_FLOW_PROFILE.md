# МОСТ / LITHOS::FLOW — русскоязычный предметный профиль

**Профиль:** LITHOS::FLOW 1.0.0  
**Реестр ключевых написаний:** МОСТ 0.3.0  
**Статус:** расширенный лексический слой и исполняемый reference-runtime пример. Это не отдельный язык и не новая грамматика.

## Русский слой

МОСТ сохраняет одну грамматику Reaper и переводит точные русские написания в существующие канонические токены до разбора.

| Поверхность | Количество | Состояние |
|---|---:|---|
| Точные русские написания | 102 | версионируемый реестр |
| Исполняемые в текущем reference subset | 38 | канонические токены поддерживаемой грамматики |
| Лексически зарезервированные | 64 | распознаются лексером, но не означают поддержку грамматики |
| LITHOS-предметные имена | 44 | обычные Unicode-идентификаторы / имена пользовательских процедур |

Новые русские исполняемые формы включают: объявить, создать, присвоить, перезаписать, напечатать, показать, когда, каждый, среди, повторять, верно, неверно, пусто, либо, подключить, опубликовать, под_именем.

Реестр language/most_keyword_aliases.json задаёт точное соответствие. Склонение, эвристические синонимы и угадывание форм не выполняются. Неперечисленное слово остаётся обычным идентификатором.

## Предметная лексика LITHOS

language/most_lithos_vocabulary.v1.json содержит русскоязычный словарь домена: блоки, коридоры, подвалы, шлюзы, узлы, связи, поля, слои, давление, целостность, шум, сигнал, исток, корень, несущая ось, фазы, пороги, ритм, пульсация, синхронизация, связность, подлинность, накрутка, пересборка, восстановление и устойчивость.

Эти слова — имена предметной области, а не встроенные команды. Например, усилить_опору становится исполняемой процедурой только после того, как автор программы объявит такую процедуру. Сам реестр не создаёт реализацию, системное право или скрытый побочный эффект.

## Отображение LITHOS-концепций на Reaper

| Концепция | Допустимая запись сейчас | Граница реализации |
|---|---|---|
| WEAVE / Genesis | пользовательские функции, списки и явные связи | нет отдельного оператора WEAVE/СПЛЕСТИ |
| Rose / Razor | функции и явные значения результата | TRY/CATCH/FINALLY не добавлены в грамматику |
| Сетка 4/4 | числа, счётчики и loop while | нет аудио-движка или музыкального планировщика |
| Holographic Backbone | обычные записи, значения и проверки инвариантов | нет встроенных HOLOGRAM/BONE runtime-сущностей |
| Undercurrent | ограниченный поиск по явным данным | нет «указателя веры» или скрытых API |
| Basement / Null Score | значение пусто / nothing внутри программы | это не делает процесс невидимым внешним системам оценки или наблюдения |
| Glitch Adapter | обработка произвольного текста как данных | шум не является криптографической энтропией и не генерирует ключи |
| Global Policing Override | моделирование перспективы и событий в пользовательских данных | нет обхода наблюдения, приватности или системной политики |
| Типы и жизненный цикл | текущие поддерживаемые конструкции и зарезервированные слова | полный TYPE/METHOD/OWNERSHIP синтаксис не заявлен |
| Nature / Rest | функции и данные предметной модели | нет биологического приоритета планировщика ОС |
| Post-Soviet / Drill / Industrial | обычные строки, имена, числа и данные приложения | нет специального режима парсинга лирики или фонетической компиляции |
| Exit / Narrative Pivot | обычное управление потоком в пределах запуска | нет долгоживущего SUSPEND/AWAIT/RESUME сервиса |

## Сохраняемые инварианты

- Оператор :: остаётся существующим оператором передачи данных Reaper; не переопределяется.
- Оператор || остаётся логическим OR; не переопределяется под контраст или связь.
- Все поддерживаемые русские формы проходят через тот же парсер, AST, семантику и runtime, что и канонические английские формы.
- Лексическая резервация не подтверждает парсер, типизацию, генерацию кода или выполнение.
- Любая новая конструкция требует грамматического RFC, реализации, негативных/позитивных тестов, parity-проверок и CI evidence.
- Ключевые слова не предоставляют файловые, сетевые, аппаратные, криптографические или привилегированные права.

## Исполняемый пример и проверка

Пример: examples/lithos_flow_ru.most.

Проверки:
- Python reference runtime: tests/test_most_lithos_flow.py;
- native C17 lexer: tests/test_most_extended_russian_aliases.c;
- единый registry/native parity validator: tools/validate_most_keywords.py.

Пример использует только уже поддерживаемую грамматику и исполняемые псевдонимы МОСТ. Он демонстрирует расчёт усиления целостности, ослабления шума, средней связности и фильтрацию сигнала, но не активирует физические или сетевые операции.
