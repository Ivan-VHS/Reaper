# Architecture 66 — compact contract

| Rules | Domain | Acceptance focus |
|---|---|---|
| 1–11 | product/core | one language, modular runtime, narrow APIs |
| 12–22 | independence | offline, no hidden dependencies/effects |
| 23–33 | semantics | explicit flow, mutability, conversion and quotas |
| 34–44 | modules | testable layers, adapters and compatibility |
| 45–55 | resources | bounds, cancellation, deterministic errors |
| 56–66 | governance | evidence, exact PR head, human approval and rollback |

All 66 rules are requirements, not 66 shipped capabilities.
