# Русскоязычный профиль языка Reaper

**Назначение:** сделать русский полноценным читаемым вариантом записи существующего языка Reaper, не создавая второй runtime и не меняя семантику уже работающих программ.

**Текущий статус:** русские ключевые слова реализованы в Python reference lexer/interpreter как точные псевдонимы существующих токенов. Нативный C17 lexer распознаёт основной русский словарь как зарезервированные ключевые слова. Это ещё не означает, что нативный C-парсер или MOST уже исполняют всю русскую грамматику.

## Принципы

1. **Один язык, несколько написаний.** Русские и английские ключевые слова сходятся к одним и тем же внутренним видам токенов.
2. **Семантика не угадывается.** Синонимы не добавляют новых типов, операций, побочных эффектов или полномочий.
3. **Кириллица — обычная часть исходника.** Имена функций, переменных и модулей можно писать кириллицей; ключевые слова профиля зарезервированы и пишутся в нижнем регистре.
4. **Совместимость.** Существующий синтаксис Reaper (make, vary, change, craft, yield, emit, when, each, loop while) продолжает работать.
5. **Проверяемость.** Любой новый псевдоним должен соответствовать одному каноническому токену и проходить лексические и исполняемые тесты.
6. **Разделение Reaper и MOST.** Русский слой reference-языка Reaper не объявляется полным русским фронтендом MOST. Для MOST требуется отдельное расширение грамматики, AST, типизации и native/WASM conformance.

## Русские ключевые слова

| Канонический токен | Русские написания | Значение |
|---|---|---|
| MAKE | пусть, создать, неизменяемое, неизменяемая | Неизменяемое объявление |
| VARY | изменяемая, изменяемый, переменная | Изменяемое объявление |
| CHANGE | изменить, присвоить, переприсвоить | Явное изменение значения |
| CRAFT | функция, процедура | Объявление функции |
| YIELD | вернуть, возвратить | Возврат результата |
| EMIT | вывести, показать, напечатать | Вывод значения |
| WHEN | если, когда | Условное выполнение |
| OTHERWISE | иначе | Альтернативная ветвь |
| EACH | каждый, для | Перебор последовательности |
| IN | в, среди | Связка переменной цикла с последовательностью |
| LOOP / WHILE | цикл / пока | Цикл с условием: «цикл пока условие { ... }» |
| TRUE / FALSE | истина / ложь | Логические литералы |
| NOTHING | ничего, пусто | Отсутствующее значение |
| AND / OR / NOT | и / или / не | Логические операции |
| IMPORT / EXPORT / AS | импорт / экспорт / как | Подключение и экспорт модулей |

В Python-лексере исходное написание токена сохраняется для диагностики. Внутренний тип токена совпадает с английским ключевым словом. В C17-лексере русский словарь распознаётся как REAPER_TOK_KEYWORD; полноценная native-грамматика остаётся отдельным этапом.

## Пример русскоязычной программы

    пусть исходные := [1, 2, 3, 4]

    функция удвоить(значение) {
        вернуть значение * 2
    }

    пусть итог := исходные :: map(удвоить) :: sum()

    если итог > 10 {
        вывести "Сумма: " ++ text(итог)
    } иначе {
        вывести "Недостаточно"
    }

    изменяемая счётчик := 0
    для число среди исходные {
        изменить счётчик := счётчик + число
    }

    цикл пока счётчик < 11 {
        изменить счётчик := счётчик + 1
    }

    вывести счётчик

Оператор потока ::, стандартные операции, правила типов времени исполнения, пределы коллекций и диагностика остаются теми же, что и в английской записи.

## Двадцать проектных направлений

| № | Формула направления | Инженерное значение | Состояние |
|---:|---|---|---|
| 1 | Язык программирования — русскоязычный — смешать | Единый русскоязычный профиль вместо набора несовместимых диалектов | Реализован лексический слой |
| 2 | Программный язык — русский — внедрить | Русские слова для объявлений, функций, вывода, условий и циклов | Реализованы псевдонимы ядра |
| 3 | Кодовый язык — отечественный — разработать | Собственная терминология, документация, редакторские средства и проверяемая сборка | Специфицировано; инструментальная интеграция продолжается |
| 4 | Алгоритмический язык — национальный — сделать | Алгоритмы, арифметика и композиция используют общую семантику Reaper | Базовые операции уже есть; расширение тестируется отдельно |
| 5 | Машинный язык — родной — придумать | Русские термины для низкоуровневого интерфейса без подмены машинного кода | Русские лексемы распознаются C17-лексером; backend не заявлен готовым |
| 6 | Формальный язык — исконный — адаптировать | Явная грамматика, однозначная семантика и воспроизводимая диагностика | Контракт описан; полная формальная грамматика ещё развивается |
| 7 | Компьютерный язык — самобытный — улучшить | Узнаваемый стиль Reaper с явной композицией потоков | Оператор :: и общий runtime уже существуют |
| 8 | Вычислительный язык — славянский — модернизировать | Кириллические имена, UTF-8-текст и единые вычислительные правила | Unicode-идентификаторы reference-лексера поддерживаются |
| 9 | Системный язык — восточнославянский — выполнить | Связать русскую поверхность с системным направлением MOST | MOST остаётся отдельным типизированным треком; русская грамматика MOST не завершена |
| 10 | Инструкционный язык — литературный — каталогизировать | Словарь ключевых слов, терминов и команд с точным назначением | Словарь ключевых слов внесён в код и документацию |
| 11 | Командный язык — народный — унифицировать | Простые глагольные формы для повседневных команд языка | Основные команды сведены к каноническим токенам |
| 12 | Синтаксический язык — общенародный — универсализировать | Несколько читаемых русских вариантов без разветвления грамматики | Реализовано через таблицу псевдонимов |
| 13 | Семантический язык — коренной — уникализировать | Синонимы не меняют значение операции и не включают скрытые эффекты | Обеспечено общей токенизацией и существующим runtime |
| 14 | Декларативный язык — традиционный — защитить | Будущие декларативные конструкции с проверяемым контрактом | Запланировано; не объявляется реализованным |
| 15 | Императивный язык — аутентичный — монолитность | Цельная модель присваивания, условий и циклов при модульной реализации компилятора | Базовые конструкции Reaper уже исполняются |
| 16 | Процедурный язык — нативный — самостоятельность | Функции и процедуры не зависят от языка записи исходника | Функции и замыкания реализованы; native execution остаётся отдельным этапом |
| 17 | Объектный язык — местный — собственность | Локальная модель объектов и свойств с явным владением | Запланировано; полноценная объектная модель отсутствует |
| 18 | Модульный язык — русскоговорящий — защита прав | Русские имена модулей и единые правила импорта/экспорта | Система .rpr import/export существует; юридическая политика описана ниже |
| 19 | Универсальный язык — русскоязычный — защита чужих прав | Совместимость с внешними проектами при сохранении авторства, лицензий и уведомлений | Политика зафиксирована; автоматический юридический аудит не заявлен |
| 20 | Исполняемый язык — русский по происхождению — вайбинг | Удобная интерактивная работа, понятные примеры и быстрая обратная связь | REPL и Reaper Studio существуют; русская запись проходит reference runtime |

Слова «национальный», «отечественный» и «родной» здесь обозначают языковую локализацию и самостоятельность инструментария, а не исключительность, закрытие экосистемы или запрет на другие языки.

## Проверка

    python -m unittest discover -s tests -v
    cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
    cmake --build build --parallel
    ctest --test-dir build --output-on-failure

Новые Python-тесты проверяют русские псевдонимы и исполнение примеров. Нативный C17-тест проверяет распознавание ключевых слов и сохранение кириллических имён как идентификаторов. Результаты проверки должны подтверждаться CI PR.

## Границы реализации

- Русская запись исполняется в Python reference runtime только для перечисленных конструкций существующего ядра.
- Нативный C17 lexer распознаёт новые слова, но его текущая грамматика не является полным русским frontend.
- Self-hosting lexer пока имеет известное ограничение ASCII-идентификаторов.
- Полная русская грамматика MOST, статическая типизация, объектная модель, нативная генерация кода и WASM не включаются в статус реализованных этим изменением.
